# Provenance

The reference experience was designed and developed by **Ravi Klaassens**:

- Reference: https://a24.raviklaassens.com/
- Creator: https://raviklaassens.com/

`public/vendor/reference.css`, `main.qdXy8l6N.js`, `bootstrap.dru0MhUJ.js`, the preload helper, Three.js modules and lighting helper were downloaded from the reference’s public assets. The source’s geometry, procedural disc textures, lighting, drag/scroll physics, scribble renderer, preloader, navigation, dissolve and page-transition code are reused. These are adaptations of the reference implementation, not newly authored equivalents.

Local runtime changes are limited to the S10 loader label and 2017–2026 range, music-specific accessibility/collection labels, music-player naming, editorial caption formatting and the project-specific console notice. Source layout templates retain the reference’s structural hooks. The surrounding build scripts, server, song data and recovery module implement this adaptation.

The source bundles GSAP (including CustomEase, ScrollTrigger and SplitText), Lenis, Barba.js and Three.js. Original embedded license notices are retained. The supplied PP Eiko, PP Museum and PP Neue Montreal font files are copied from the reference’s public font assets. Font and source-asset rights remain with their respective owners.

Song covers come from the Spotify artwork URLs in the user-supplied manifest. Detail-page stills are official YouTube release thumbnails. The CD soundtrack uses the ten recordings subsequently supplied in `assets/music/`, with web playback copies prepared in `public/music/`. The separate video overlay uses YouTube’s player. Spotify buttons point directly to the relevant track.

The official Seedhe Maut logo is sourced from:
https://www.seedhemaut.com/wp-content/uploads/2025/08/Sm-header-logo.svg

The duo sticker image was supplied in the project’s original `assets/` folder. All music, artwork, branding and supplied images remain the property of their respective rights holders. This is an unofficial local tribute, with no affiliation or endorsement asserted.
